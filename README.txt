TYEI WEBSITE - PROJECT NOTES
============================

HOW TO OPEN
1. Extract this ZIP file.
2. Open the tyei folder.
3. Double-click index.html to view the website in a browser.
   You can also open the folder in VS Code and use Live Server.

PROJECT FILES
- index.html: website content and sections
- css/style.css: layout, colours, typography and responsive design
- js/main.js: mobile navigation and membership enquiry form
- images/: TYEI logo and emblem
- assets/TYEI_Constitution.docx: organization constitution

IMAGE NOTES
The homepage hero banner and gallery use illustrative Pexels stock photographs
loaded from the internet. An internet connection is required to display them.
They are not photographs of actual TYEI programmes or members. Pexels' licence
allows free website use; review https://www.pexels.com/license for its terms.

BEFORE PUBLISHING
- The membership enquiry form sends to twapiayouthempowermentinitiative26@gmail.com. Confirm this address is monitored before publishing.
- Confirm all organizational wording, contacts and membership details.
- Replace stock photos with real TYEI photos when available and approved.
